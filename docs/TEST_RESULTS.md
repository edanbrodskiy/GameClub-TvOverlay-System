## Проверки таймера

На реальном TCL проверены:

1. Фактический foreground независимо через Android dumpsys.
2. Четыре карточки 15/5/1 минута/30 секунд; повторы не создают дополнительные окна.
3. Автоматическое скрытие уведомления через 10 секунд.
4. Реальные отсчёты 61/31 с пересекают пороги 60/30 с с правильным предупреждением.
5. Сеанс на 3 с истекает → TIME IS UP; продление скрывает окно; Hide отменяет новый срок.
6. Продление активного сеанса предотвращает срабатывание прежнего срока окончания.
7. Hide отменяет следующую запланированную карточку демонстрации.
8. Вход HDMI400004 и фокус `com.tcl.tv/com.tcl.tv.TVActivity` сохраняются через все тесты.

JVM-тесты покрывают пороги, пропуск устаревших уведомлений, короткие сеансы,
повторное подтверждение, продление активного и истёкшего сеанса, отмену,
приоритет истечения, уже истёкший срок, монотонный отсчёт и максимум 24 часа.

## Особенность foreground на TCL

В 0.1.0 в логах обнаружены `ForegroundServiceDidNotStartInTimeException`:
TCL отвергает фоновые вызовы `startForeground` с причиной `default_borbid`.
Наличие окна и `service_running=true` не гарантирует фактический foreground.

В 0.2.0 добавлено поле `foreground_service`, которое проверяет состояние Android.
Команда `tv.sh activate` открывает администратора, запускает сервис, ждёт реального
подтверждения foreground и только затем возвращает прежнюю Activity. После этого
команды передаются уже работающему сервису без повторных foreground-запусков.
`APP_AUTO_START=allow` выдан только нашему пакету, но сам по себе не устраняет
это ограничение TCL. Глобальные ограничения и другие приложения не менялись.
Автозапуск после reboot не заявляется; после force-stop нужна повторная активация.

## Сборка и повторение

```bash
./scripts/build.sh
./scripts/tv.sh install
./scripts/tv.sh activate
python3 scripts/timer_smoke_test.py --serial 192.168.10.53:5555 --artifacts artifacts/timers-tcl
./scripts/tv.sh demo
```

Тесты меняют локальный тестовый сеанс; запускать только на свободном устройстве.
Таймер APK пока не связан с оплатой/ggLeap. При перезапуске процесса он сбрасывается,
ложная блокировка не восстанавливается.

## Упаковка проекта

Исходники перенесены в корень Android-проекта. Чистая сборка, 11 JVM-тестов и Lint
пройдены после переноса. JDK и временный эмулятор не включаются в исходный архив.
Архив успешно проверен сборкой из распакованной копии без local.properties:
assembleDebug, lintDebug и все 11 JVM-тестов прошли. Исходный комплект содержит
Gradle Wrapper, ресурсы, тесты и документацию; локальные пути SDK/JDK в него не входят.
