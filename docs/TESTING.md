# Проверки

## Локально

```bash
./scripts/build.sh
```

Выполняются сборка APK, Lint и 11 JVM-тестов таймера. Проверяются пороги 15/5/1
минута/30 секунд, задержанные тики, короткие сеансы, повторные подтверждения,
продление, отмена, истечение, монотонный отсчёт и лимит длительности.

## На тестовом устройстве

Скрипты временно показывают окна и меняют локальный тестовый сеанс. Запускайте
только на свободном устройстве; серийный номер ADB указывается явно.
JSON, дампы и доступные скриншоты сохраняются в игнорируемую папку `artifacts`.

Базовый тест переключает устройство на Android Home, меняет overlay AppOps,
проверяет 20 циклов show/show/hide/hide, отказ без разрешения, отмену задержанного
показа и жизненный цикл сервиса. В конце выполняет force-stop нашего пакета:

```bash
python3 scripts/smoke_test.py --serial emulator-5580 --artifacts artifacts/basic
```

Тест таймера сохраняет текущий вход. На TCL сначала активируйте foreground-сервис:

```bash
./scripts/tv.sh activate
python3 scripts/timer_smoke_test.py --serial 192.168.10.53:5555 --artifacts artifacts/timers
```

Он проверяет реальный foreground через dumpsys, четыре карточки без дубликатов,
автоскрытие, пересечение 60/30 секунд, окончание, продление, отмену и сохранение
активного входа. Фокус сравнивается по Activity, поскольку TCL может пересоздавать
Window без смены входа. В конце окна скрываются, таймер отменяется.

## Визуальная проверка HDMI

```bash
./scripts/tv.sh demo
```

При включённой PS5 на HDMI 4 проверьте все четыре карточки, полноэкранный финал,
отсутствие просветов и возврат к PS5 после скрытия. На проверенном TCL HDMI не
попадает в screencap; дамп WindowManager не заменяет визуальную проверку.

Дополнительно перед внедрением нужны 30 минут удержания окна, переключение
Home → HDMI 4 при активном оверлее, восстановление после сети и проверка reboot.
Их текущий статус указан в [результатах](TEST_RESULTS.md).

## Проверка упаковки

```bash
python3 scripts/package.py
```

Контрольные суммы записаны относительно папки `dist`:

```bash
(cd dist && shasum -a 256 -c SHA256SUMS)
```

Архив исходников включает Gradle Wrapper, ресурсы, тесты и документацию.
В него не входят `local.properties`, APK, JDK, SDK, кэши, временные дампы и ключи подписи.
